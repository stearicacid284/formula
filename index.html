数式・化学式を綺麗に作るコツ

💡 1. パレットと「次の { } へ」ボタンの活用

パレットのボタンをタップすると、カーソル位置にコマンドが挿入され、最初の入力箇所（分子など）に自動でカーソルが入ります。分母や次の引数に移りたいときは、エディタ上の「次の { } へ」ボタンをタップすると素早く移動できます。

🧪 2. 化学式は \ce{...} が超便利！

MathJaxの化学拡張（mhchem）を搭載しているため、\ce{H2O} と書くだけで自動的に下付き文字の $\text{H}_2\text{O}$ になります。
・イオン：\ce{SO4^2-} → $\text{SO}_4^{2-}$
・可逆反応：\ce{N2 + 3H2 <=> 2NH3}
・沈殿・気体：\ce{AgCl v}（$\downarrow$）、\ce{H2 ^}（$\uparrow$）

📐 3. 大きいカッコを自動調整するには

分数の外側を囲むカッコは、普通の ( ) ではなくパレットの「自動伸縮 ( )」（\left( \sim \right)）を使うと、分数の高さに合わせて美しいサイズに自動伸縮します。
